## 📊 About This Project
A data analysis portfolio combining two critical themes about Malaysia:
- **Theme 1**: Demographic shifts — Malaysia's ageing population (1970–2025)
- **Theme 2**: Cost of living crisis — Can household income keep up with inflation?

## 🛠 Tools Used

|----------|-----------|-----------------|
| Python, R, JupyterLab | Tableau Public, Power BI | Git & GitHub |
